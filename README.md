### Programming in a nutshell
> Programming is the art of giving precise instructions, in expectation of solving a problem. People Use it for various  tasks, such as: system programming, developing games, operating systems, and what not!

#### Language To start with ❓
 > * We recommend starting with Python, as it is quite easy, and comprehensible for most beginners, *Html* or *JavaScript* can be the alternates, if we want to do web development.

> > * You may see a comparison table of languages, compared in terms of complexity and use case; so, you don't waste half of your time choosing your first language.

##
| Language | Use Case | Complexity |
|-----------|-----------|------------|
| `Python` | Automation, AI, web development, scripting | Low |
| `JavaScript` | Frontend and backend web development | Medium |
| `TypeScript` | Large scale web applications | Medium |
